# Security and safety boundary

MockMill does not connect to CRMs, send communications, create meetings or authorize writes. The five adapters produce offline CSV/JSON fixtures and dry-run plans only. Never place credentials, tokens, real customer data or production exports in this repository.

Report suspected secrets or privacy issues privately to the repository owner. Do not open a public issue containing sensitive material. Until a public repository and license are explicitly approved, this local candidate has no public vulnerability-reporting SLA.
